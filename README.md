# Система настройки пользовательских профилей

Консольное приложение для управления профилями пользователей, их
настройками и параметрами.

## Возможности

- просмотр и поиск профилей;
- просмотр настроек профиля и параметров настройки;
- добавление профилей, настроек и параметров;
- изменение значения параметра с проверкой допустимости;
- проверка значения параметра без его изменения;
- отбор параметров по типу и сортировка по ключу;
- сброс параметра к значению по умолчанию;
- хранение данных между запусками приложения.

## Предметная область

Система хранит профили пользователей. Каждый профиль объединяет несколько
настроек (категорий, например «Внешний вид» или «Уведомления»), а каждая
настройка содержит набор параметров — именованных значений определённого
типа (`str`, `int`, `bool`) с допустимым диапазоном или множеством значений.

## Основные сущности

### Профиль
Именованный набор настроек пользователя.
Атрибуты: `id`, `name`, `owner`, `description`.

### Настройка
Категория параметров профиля.
Атрибуты: `id`, `profile_id`, `category`.

### Параметр
Именованное значение настройки.
Атрибуты: `id`, `setting_id`, `key`, `value`, `value_type`,
`default_value`, `min_value`, `max_value`, `allowed_values`.

## Основные операции

### Работа с профилями
- добавление профиля;
- поиск профиля по названию;
- сортировка профилей;
- просмотр списка профилей.

### Работа с настройками
- добавление настройки;
- поиск настроек профиля;
- поиск настройки по категории;
- просмотр списка настроек.

### Работа с параметрами
- добавление параметра;
- проверка допустимости значения (тип, диапазон, список значений) —
  как отдельно (`validate_parameter_value`), так и в связке с поиском
  параметра по ключу (`check_parameter_value`), без изменения самого
  параметра;
- изменение значения параметра;
- сброс параметра к значению по умолчанию;
- отбор параметров по типу значения (`filter_parameters_by_type` —
  реализовано как генератор);
- сортировка параметров по ключу (`sort_parameters_by_key` —
  используется lambda-функция);
- просмотр списка параметров.

При изменении параметра проверяется соответствие нового значения типу
параметра и, при наличии, диапазону или списку допустимых значений.

## Хранение данных

Данные приложения хранятся в JSON-файлах:

- `data/profiles.json`;
- `data/settings.json`;
- `data/parameters.json`.

## Назначение модулей

### `main.py`
Точка входа в приложение. Отвечает за запуск приложения, отображение
меню, получение данных от пользователя и организацию пользовательских
сценариев.

### `profiles.py`
Функции работы с профилями.

### `settings.py`
Функции работы с настройками.

### `parameters.py`
Функции работы с параметрами: создание, поиск, проверка, изменение и
сброс значений, а также отбор по типу (генератор) и сортировка по
ключу (lambda-функция).

### `storage.py`
Отвечает за загрузку и сохранение данных. Выполняет преобразование
JSON → список словарей и обратно.

### `utils.py`
Содержит вспомогательные функции безопасного ввода: `input_int()`,
`input_choice()`.

### `tests/`
Содержит автоматизированные тесты проекта.

## Запуск приложения

```text
python main.py
```

После запуска отображается главное меню.

## Тестирование

Для запуска автоматизированных тестов выполнить:

```text
pytest -v
```

Тесты проверяют создание, поиск, сортировку записей о профилях,
настройках и параметрах, а также проверку допустимости значений,
изменение и сброс значений параметров.

## Проверка качества кода

Для проверки соответствия кода требованиям PEP 8 используется `flake8`:

```text
flake8 .
```

## Целевая аудитория

Пользователи веб- и десктоп-приложений, которым требуется гибко
настраивать внешний вид, уведомления и параметры приватности под себя,
а также администраторы, задающие значения настроек по умолчанию.
