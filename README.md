# Система настройки пользовательских профилей

## Назначение

Приложение позволяет пользователям управлять персональными профилями:
группировать настройки по категориям и задавать значения параметров
с проверкой их корректности (типа, диапазона или списка допустимых значений).

## Целевая аудитория

Пользователи веб- и десктоп-приложений, которым требуется гибко настраивать
внешний вид, уведомления и параметры приватности под себя, а также
администраторы, задающие значения настроек по умолчанию.

## Предметная область

Система хранит профили пользователей. Каждый профиль объединяет несколько
настроек (категорий, например «Внешний вид» или «Уведомления»), а каждая
настройка содержит набор параметров — именованных значений определённого
типа с допустимым диапазоном или множеством значений.

## Основные сущности

- Пользователь — владелец одного или нескольких профилей;
- Профиль — именованный набор настроек пользователя (например, «Рабочий»,
  «Личный»);
- Настройка — категория параметров профиля (например, «Внешний вид»,
  «Уведомления», «Приватность»);
- Параметр — конкретное именованное значение настройки (например, тема
  оформления, размер шрифта, включены ли уведомления).

## Основные функции

- проверка допустимости значения параметра (диапазон, тип, список
  допустимых значений);
- формирование текстового статуса параметра;
- формирование описания параметра профиля для вывода пользователю.

## План развития

На следующих этапах планируется:

- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
